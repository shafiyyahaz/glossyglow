GLOSSYGLOW — LUXURY EDITION
============================
Website statis untuk GitHub Pages, dengan foto visual berbeda untuk tiap produk.

FILE:
- index.html: struktur website
- style.css: desain responsif pink luxury
- script.js: katalog produk contoh, keranjang demo, Sweet Notes, dan newsletter demo
- assets/: gambar visual GlossyGlow dan favicon

CARA PAKAI:
1. Ekstrak ZIP ini.
2. Buka index.html di browser untuk melihat preview.
3. Untuk GitHub Pages, unggah semua isi folder ini ke repository (pastikan index.html berada di root).
4. Ganti nama produk, harga, foto, dan detail sesuai produk asli.

CATATAN:
- Nama dan harga produk merupakan contoh.
- Foto adalah visual konsep kosmetik untuk desain, bukan foto produk komersial terverifikasi.
- Keranjang hanya demo frontend; tidak ada pembayaran, database, stok, atau pemrosesan pesanan nyata.
- Form newsletter hanya memberi konfirmasi di halaman dan tidak menyimpan alamat email.
- Jangan gunakan klaim BPOM/sertifikasi tanpa verifikasi produk asli.
